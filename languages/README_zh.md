一款购物调研浏览器扩展：悬停商品一键采集快照——标题、价格、链接、型号、站点、日期自动保存到本地资料库，并自动跟踪价格历史。

## 为什么选 VKT Item Pin？

跨站点比价通常意味着开一堆标签页、反复复制粘贴到表格。VKT Item Pin 让你悬停任意商品、点击 **Pin**，就能沉淀一个持续更新价格的商品资料库。

| 优势 | 说明 |
|------|------|
| 🎯 **悬停即采集** | 悬停商品点击 Pin 按钮——标题、价格、链接、型号、站点、日期自动提取 |
| 📈 **价格历史** | 同一商品随时重复采集，每次追加一个价格点，自动生成走势图 |
| 🛒 **24 站点预设** | Amazon、eBay、Etsy、Walmart、速卖通、Temu 等手调选择器，其余站点走通用引擎（JSON-LD / OG / 通用选择器） |
| 🖼️ **商品缩略图** | 每条记录保存商品图片 |
| 🔒 **隐私优先** | 数据仅存浏览器本地（`chrome.storage.local`），绝不上传 |

## 安装

1. 打开浏览器扩展页：Chrome `chrome://extensions/`、Edge `edge://extensions/`
2. 开启右上角**开发者模式**
3. 点击**加载已解压的扩展程序**，选择 `vkt-item-pin` 文件夹
4. 在任意购物页面悬停商品，点击 📌 Pin 按钮

## 使用方法

### 采集商品

1. 悬停任意商品（详情页或搜索结果网格均可）——出现 📌 按钮
2. 点击后右侧滑出预览面板，显示已提取的标题、价格、链接、型号、站点、日期
3. 修改任意字段，缺失字段用**拾取**补全，然后点击**保存**

### 跟踪价格

- 对已保存的商品再次采集，自动追加一个价格点（已跟踪商品不占免费额度）
- 打开仪表盘查看走势图，或用**对比**（Pro）把多个商品叠加比较

### 备份

- 仪表盘底部有**备份 JSON / 导入**功能，建议定期备份——数据只存在浏览器里

## 工作原理

```
悬停商品 → 点击 Pin
       ↓
提取引擎运行（JSON-LD → 站点预设 → 通用 → 正则）
       ↓
预览面板：编辑 / 拾取字段
       ↓
URL 归一化去重后存入 chrome.storage.local
       ↓
再次采集追加价格点 → 仪表盘生成走势图
```

所有提取和存储均在本地完成。唯一的网络请求是**可选的**：激活 Pro 授权密钥时，扩展会向授权服务器发送密钥和基本浏览器信息（浏览器、语言、时区），绝不读取或上传任何网页内容。

---

## 隐私

- `storage` — 本地保存商品资料库，网页内容不出浏览器
- `scripting` + `activeTab` — 仅在您与页面交互时注入 Pin 按钮 / 提取字段
- `<all_urls>` — 让扩展在所有购物站点可用，绝不后台读取或上传页面内容
- 无追踪、无分析。唯一的网络请求是使用 Pro 授权密钥时的授权激活/验证
