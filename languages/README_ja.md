# VKT Item Pin

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

ショッピングリサーチ用ブラウザ拡張：商品にカーソルを合わせるだけでスナップショットを保存。タイトル・価格・リンク・型番・サイト・日付をローカルライブラリに記録し、価格履歴も自動で追跡します。

> Chrome / Edge / Firefox · Manifest V3 · 最小権限 · トラッキングなし · 100% ローカル

---

## VKT Item Pin の特徴

複数のショッピングサイトで商品を比較するのは、タブを大量に開いて表にコピペする作業になりがちです。VKT Item Pin なら商品にカーソルを合わせて **Pin** をクリックするだけで、価格履歴付きの商品ライブラリをブラウザ内に育てられます。

| メリット | 詳細 |
|----------|------|
| 🎯 **ホバーで保存** | 商品にカーソルを合わせ Pin をクリック——タイトル・価格・リンク・型番・サイト・日付を自動抽出 |
| 🔁 **価格の自動記録** | すでに保存した商品ページを開くだけで価格を自動記録。もう一度クリックする必要はありません |
| 🔔 **ローカル値下げ通知** | 商品ごとに目標価格を設定。初めて下回ったときにデスクトップ通知——サーバーもメールも使いません |
| 📈 **価格履歴** | 手動でも自動でも価格ポイントが追加され、商品ごとのトレンドチャートが育ちます |
| 🛒 **24 サイト対応** | Amazon・eBay・Etsy・Walmart・AliExpress・Temu などを手動チューニング。その他のサイトは汎用エンジン（JSON-LD / OG / 汎用セレクタ）で対応 |
| 🏷 **メモ & タグ** | 「ブラックフライデーまで待つ」などの理由を残せ、タグは 1 商品 10 個まで。どちらも検索できます |
| 🖼️ **サムネイル** | 商品画像も記録と一緒に保存 |
| 🔒 **プライバシー優先** | データは `storage.local` でブラウザ内にのみ保存。アップロードは一切なし |

## 対応サイト

**手動チューニング済み（24 サイト）**：Amazon（全マーケットプレイス）、eBay、Etsy、Walmart、Target、AliExpress、Temu、Best Buy、Home Depot、Lowe's、Newegg、Wayfair、Mercari、Shopee、Lazada、楽天、SHEIN、Alibaba.com / 1688、DHgate、TikTok Shop、bol.com、Allegro、Otto.de、Cdiscount など

**その他すべて**（Shopify / WooCommerce / 独自サイト）は汎用エンジンがカバー：JSON-LD 構造化データ → Open Graph タグ → 汎用セレクタ → 正規表現フォールバック → 手動選択モード。

## 使い方

### 商品を保存

1. 商品にカーソルを合わせる（詳細ページでも検索結果グリッドでもOK）——📌 ボタンが表示されます
2. クリックするとサイドパネルが開き、抽出されたタイトル・価格・リンク・型番・サイト・日付が表示されます
3. 必要に応じて修正し、不足フィールドは**選択**で補完して**保存**をクリック

### 価格を追跡

- 保存済みの商品ページを開くだけで、価格が自動で記録されます（1 日 1 ポイントまで。無料プランで保存できるのは最大50商品で、保存済み商品の価格を再記録しても新しいレコードは増えず、枠も消費しません）
- ダッシュボードで**目標価格**を設定すると、その価格以下になった回にデスクトップ通知が出ます。跨いだ瞬間に 1 回だけで、繰り返し通知はしません
- ダッシュボードでトレンドチャート・直近 30 日の値下げ集計を確認、または**比較**（Pro）で複数商品を重ねて表示
- **メモ**と**タグ**で「なぜ待つ価値があるか」を残せます

### バックアップ

- ダッシュボードのフッターに**JSON バックアップ / インポート**があります。データはブラウザ内のみに存在するため、定期的なバックアップを推奨します

## 仕組み

1. 商品にカーソルを合わせ、📌 Pin ボタンをクリックします。
2. プレビューパネルで確認し、残したいフィールドを編集したり、**選択**モードでページから補完したりできます。
3. 商品はブラウザ内に保存され、同じリンクの記録は 1 件に統合されます。
4. 同じ商品を再訪すると、価格が自動で記録されます（1 日 1 ポイント）。
5. 目標価格以下になった瞬間にはデスクトップ通知が出、ダッシュボードが価格推移をチャート化します。

抽出も保存もすべてブラウザ内で完結します。ネットワーク通信は次の 2 つの任意のケースに限られます：(1) Pro ライセンス認証/検証時に、キーと基本的なブラウザ情報（ブラウザ・言語・タイムゾーン）をライセンスサーバーへ送信します。(2) ポップアップやダッシュボードで保存済み商品のサムネイルを表示する際、ブラウザが元のストアの画像 URL を直接読み込みます。ページの内容や収集データがアップロードされることは一切ありません。

## プライバシー

- `storage` — ライブラリをローカルに保存。ページの内容は外部に出ません。
- `scripting` + `activeTab` — ページを操作している間だけ Pin ボタンを注入 / フィールドを抽出。
- `notifications` — ローカルの目標価格通知にのみ使用。どこにもデータを送信しません。
- `<all_urls>` — あらゆるショッピングサイトで動作するための権限です。バックグラウンドでページ内容を読み取ったり送信したりすることはありません。
- トラッキング・アナリティクスなし。通信は Pro ライセンスの認証 / 検証と、元のストアからの商品サムネイル読み込みに限られます。
